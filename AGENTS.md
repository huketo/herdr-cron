# herdr-cron

## Agent skills

### Issue tracker

Issues live in the `huketo/herdr-cron` GitHub Issues, operated through the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles are used verbatim as label strings — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` and one `docs/adr/` at the repo root, over the normative specification in `docs/spec/` and its evidence in `docs/research/`. See `docs/agents/domain.md`.
